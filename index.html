📥 포트레이트 파일을 여기로 드래그하세요
파일명 앞의 캐릭터 이름별로 가로 한 줄씩 묶이고, - _ @ ( ) 뒤의 표정 이름이 자동 입력됩니다. (예: 김철수(화남).png)
여러 캐릭터의 파일을 한꺼번에 놓아도 됩니다. 클릭해서 선택해도 돼요.
(예: 김철수-화남.png, 김철수_웃음.png, 김철수@울음.png → 김철수 한 줄 / 김철수.png는 표정 이름 없이 김철수 줄에 포함)
💾 저장해둔 백업이 있나요? 백업(JSON)을 불러오면 이미지·이름·순서·설정이 그대로 복원됩니다.

1. 캐릭터 · 표정 정리

파일을 끌어오면 캐릭터 이름별로 줄이 만들어지고, 각 줄에 파일 목록이 표시됩니다. 카드를 드래그하면 순서를 바꾸거나 다른 캐릭터 줄로 옮길 수 있고, 🔤 버튼으로 해당 표정 이름을 숨길 수 있습니다.

2. 최종 미리보기

위에 포트레이트 파일을 드래그하면 여기에 컨닝페이퍼가 만들어집니다.

3. 시트 설정

0 = 캐릭터 한 명을 항상 가로 한 줄에 표시 (기본). 숫자를 넣으면 그 칸 수마다 줄바꿈됩니다.

세로 기준 15%

0% = 위쪽(얼굴) 기준, 100% = 아래쪽 기준 (채우기 모드)

바꾸면 현재 파일들을 다시 분류합니다.
