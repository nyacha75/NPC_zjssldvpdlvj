📥 포트레이트 파일 업로드
여러 캐릭터 파일 한번에 업로드 가능.
자동으로 캐릭터별로 묶이며, - _ @ ( ) 뒤 혹은 안의 표정 이름도 자동 입력
(예: 루티(활짝).png / 루티_부끄.png)

1. 캐릭터별 표정 정리

(1) 파일을 끌어오면 캐릭터별로 줄이 만들어지고, 각 줄에 파일 목록이 표시됩니다.
(2) 표정 카드를 드래그하면 순서를 바꾸거나 다른 캐릭터 줄로 옮길 수 있고, 캐릭터 이름 왼쪽의 ☰를 드래그하면 캐릭터 순서를 바꿀 수 있습니다.
(3) 캐릭터 줄의 이미지를 클릭하면 확대·크롭할 수 있습니다. (캐릭터 전체에 적용)

2. 컨닝페이퍼 미리보기

3. 시트 설정

0 = 캐릭터 한 명의 이미지를 한 줄에 표시

캐릭터 구분 없이 칸을 이어서 채우고, 캐릭터 이름은 첫 번째 표정의 좌측 상단에 표시됩니다. 미리보기에서 칸을 클릭해 빈칸을 넣을 수 있어요.
